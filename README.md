# 随机数生成器

受到博主耿同学的启发，竟然有诸多大能不知道用“随机数生成器”，那就让我来给大家一个我自制的完美“随机数生成器”。望数据不在儿戏！
一个完全本地运行、零依赖的随机数生成工具。双击 `index.html` 即可在浏览器中使用。

## 功能特性

- 输入下界与上界，生成区间内（含边界）的随机数

- 可设置生成数量（1~500）

- 支持 0~8 位小数（0 位 = 整数）

- **唯一值模式**：仅在整数模式下可用，自动避免重复

- **随机种子**：输入种子后可获得完全可复现的结果序列（适合教学、考试、演示）

- 结果以美观的数字卡片展示，**点击任意数字即可复制**

- 实时统计：最小值、最大值、平均值、范围

- **数值分布可视化**（Canvas 柱状图）

- 最近 5 条生成记录（localStorage 持久化），可一键恢复完整参数与结果

- 一键导出 TXT / CSV

- 深色模式 + 完全离线使用

- 响应式设计（桌面与平板均佳）

## 如何使用

1. 双击 `index.html` 文件（推荐使用 Microsoft Edge 或 Chrome）
2. 设置「下界」和「上界」
3. 调整「生成数量」（滑块或输入框）
4. 选择「小数位数」
5. （可选）打开「高级选项」启用「唯一值」或「随机种子」
6. 点击黄色大按钮 **生成随机数**
7. 点击任意结果数字卡片可单独复制；使用顶部工具栏可批量操作

### 快速预设示例
- 1~100（整数）
- 0~1（4 位小数）
- 骰子 1-6
- -10~10（2 位小数）

## 验证清单（推荐首次使用后执行）

请按照以下步骤验证功能是否正常：

**基础场景**
- 下界=1，上界=100，数量=10，小数=0 → 生成 10 个 1~100 之间的整数
- 下界=0，上界=1，数量=5，小数=3 → 生成带 3 位小数的浮点数
- 下界=-5.5，上界=5.5，数量=3，小数=2
- 下界=0，上界=1，数量=4，小数=7 → 测试高精度小数（7位）

**唯一 + 整数模式**
- 下界=1，上界=10，数量=5，小数=0，勾选「唯一值」→ 无重复数字
- 下界=1，上界=5，数量=10，小数=0，勾选「唯一值」→ 应提示“区间内可选唯一整数数量不足”

**种子可复现性**
- 启用种子，填入 `12345`，生成 5 个数（小数 2 位），记录结果
- 刷新页面，输入相同所有参数 + 相同种子 → 结果必须完全一致

**边界与错误处理**
- 下界 > 上界 → 出现红色提示且按钮不可用
- 数量输入 501 → 被限制在 500
- 唯一模式下范围过小 → 给出清晰错误提示

**交互与导出**
- 点击 3 个不同数字卡片 → 均成功复制
- 「复制全部」→ 粘贴到记事本或 Excel 正常
- 导出 CSV → 用 Excel 打开应有「序号」和「数值」两列且中文不乱码
- 深色模式切换 → 界面整体切换，刷新后保持

**历史记录**
- 生成 6 次不同结果 → 右侧历史只保留最近 5 条
- 点击某条历史 → 左侧表单参数 + 结果数字 + 分布图全部恢复
- 「清空」历史后刷新页面仍为空

**性能**
- 生成 500 个（4 位小数）→ 结果区渲染流畅，无卡顿

全部通过即表示工具可用。

## 技术说明

- 纯前端单文件实现（HTML + Tailwind CDN + 原生 JS）
- 随机性：默认使用 `Math.random()`；启用种子时使用 `mulberry32` 确定性 PRNG
- 整数生成路径避免常见浮点精度问题
- 所有数据仅存在浏览器本地（localStorage），关闭标签页或删除文件即清除
- 无任何网络请求（除首次加载 Tailwind CDN 外，后续完全离线）

## 常见问题

**Q: 为什么不能生成 10000 个数？**  
A: 为保证界面流畅与可用性，限制为 500。如需大量数据可自行修改源码中的 `max="500"`。

**Q: 种子生成的序列和 Python / Excel 的 RAND 一样吗？**  
A: 不一样。不同算法的结果序列不同，但只要使用同一个种子 + 相同参数，本工具内部结果永远一致。

**Q: 如何把这个工具做成桌面快捷方式？**  
A: 在 Windows 上右键 `index.html` → 发送到 → 桌面快捷方式。或使用浏览器「创建应用快捷方式」功能（Edge/Chrome 地址栏右侧图标）。

**Q: 可以在手机上使用吗？**  
A: 可以。界面已做响应式适配，但大批量结果在小屏上会比较拥挤，建议以 50 个以内为主。
